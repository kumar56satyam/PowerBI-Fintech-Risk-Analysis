# 📊 Fintech Risk Analysis Dashboard

An interactive **Power BI dashboard** designed to analyze loan performance, customer risk, repayment behavior, and portfolio health using DAX measures and interactive visualizations.

## 🎯 Business Problem

Financial institutions need to monitor loan performance and identify high-risk customers to reduce defaults and improve recovery.

This dashboard helps analyze:

- Loan disbursement
- Recovery amount
- Default rate
- High-risk accounts
- Employment type analysis
- Verification status
- Risk flag reasons

---

## 📈 Key Performance Indicators (KPIs)

- 💰 Total Disbursed Loan
- 💵 Total Recovery Amount
- 📉 Default Rate
- ⚠️ High Risk Accounts
- 💳 Average Ticket Size

## 💡 Key Insights

- Loan disbursement peaked during the highest-performing year.
- Salaried customers contributed the largest share of loan disbursement.
- Verification-completed customers represented the majority of approved loans.
- Default rate provides a quick overview of portfolio risk.
- Employment type plays an important role in loan recovery performance.
